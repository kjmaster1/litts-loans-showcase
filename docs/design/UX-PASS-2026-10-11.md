# UX pass — 11 October 2026

Owner brief: research UI/UX again and make another pass "as an experienced web developer
and UI/UX designer… matching highly rated enterprise software". Follows the October
redesign (`REDESIGN-2026-10.md`), which this doesn't repeat.

## Research

| Source | What we took |
|---|---|
| Pencil & Paper, *Enterprise data tables* | Right-aligned numbers, frozen first column when tables scroll sideways, sort defaults that put work first, filters that keep the page's other settings. |
| Linear / Stripe dashboard patterns; SaaS UI keyboard-shortcut guidance | `?` lists shortcuts; `/` searches the list; `G` then a letter navigates; shortcuts shown in the palette and menus; never while typing; no Ctrl/⌘/Alt chords that clash with the browser or screen readers. |
| WCAG 2.2 SC 2.1.4 Character Key Shortcuts | Single-key shortcuts can be switched off. |
| GOV.UK Design System (error summary) | Errors announced (`role="alert"`) next to the action that caused them. |
| Shopify Polaris / Pega money fields | Text input (not `type=number`), unit attached to the field, thousands separators, paste "$12,500" works. |
| Basis saved views; role-based home pages | Officers start on their own work, not the company view. |
| Deque, *negative numbers* | Keep the minus sign (already used); colour is never the only signal. |
| NN/g dashboards | Exceptions and the officer's own queue first; one strong signal per number. |

## Audit (29 pages × desktop light, desktop dark, phone)

| # | Finding | Severity | Fix |
|---|---|---|---|
| 1 | Audit log and dashboard activity showed raw codes for new events (`loans.offer.issued`) and raw subjects (`loan_offer`, `list`) | High (trust) | Labels for every event; a test fails if a recorded action has no label. Subjects read "Loan offer #2", "Mortgage quote #1 · 117 Invention Ct", "Borrower #15819" and link to the page. Filters: Loans, Mortgages, Money & reports, Settings. |
| 2 | Borrowers page was an empty search box | High | Borrower directory: standing (worst first), loans/mortgages open of total, owed, repaid/bad, last activity; sortable; filters as you type; Excel; unknown State ID offers the lending check. |
| 3 | Loan officers landed on a company dashboard built for management | High | **My work**: to chase, due in the next 7 days, deals in progress (offers/quotes), commission this week; officers are sent there from `/`; Dashboard hidden for them (`dashboard.company`). |
| 4 | No keyboard accelerators beyond Ctrl/⌘K | Medium | Shortcuts (above) with a help dialog, user-menu entry, palette footer hint, and an off switch. |
| 5 | Settings: one long form, save button at the very bottom, no sign of what changed; ranges split across columns | Medium | One row per setting with its unit; ranges on one line ("10 to 25 %"); changed fields highlighted with "Was …"; a save bar sticks to the bottom while there are changes (count, reason, Discard, Save). |
| 6 | P&L month columns scroll away from the account names | Medium | First column pinned (`.sticky-col`) on wide report tables. |
| 7 | Money fields in New loan / New quote were bare text boxes ("Loan amount ($)") | Medium | `AffixInput`: "$" / "%" / "weeks" / "a day" inside the field, thousands separators when not editing. |
| 8 | Mortgage officer form always open (loan page uses Change) | Low | Same Change/Cancel pattern as loans. |
| 9 | "— (—)" and "— · — days" placeholders on mortgages without tablet details | Low | Rates and late fee shown only when known. |
| 10 | Breadcrumbs "People" / "Admin" / "Account" on top-level pages (not places you can go) | Low | Removed — crumbs only where there's a real parent. |
| 11 | Collections: stat strip touching the table | Low | Spacing. |
| 12 | One-off "Old staff loans" form dominated the Finance overview | Low | One line with "Review and clear". |
| 13 | Tax table months as "2026-10"; text said records post "early the next month" (they cover the time since the previous record) | Low | "Oct 2026"; corrected text. |
| 14 | "30 Sept" next to "1 Oct" | Low | Three-letter months everywhere (`lib/dates.ts`). |
| 15 | Phone: page actions wrapped into two rows above the content | Low | One compact row that swipes sideways. |
| 16 | Toasts: success green 4.25:1 (fails AA) | Medium (a11y) | Toasts use the app's tokens (fixed in the origination round). |

Owner choices (2026-10-11): My work for officers — yes; shortcuts with help and off
switch — yes; borrower directory — yes; density toggle — no (one compact density).

## Verification

Chrome (Playwright) as CEO and as a loan officer: 23 behaviour checks pass (directory search
and sort, `/` focus, unknown State ID, audit labels and links, settings change count and
discard, pinned P&L column while scrolled, staff-loans panel closed, mortgage Change, `?`,
`G L`, Ctrl K, shortcuts ignored while typing, shortcuts off, officer redirect and sidebar,
no horizontal scroll at 390 px on five pages). axe-core (WCAG 2.0–2.2 A/AA): no violations
on the changed pages and the shortcuts dialog, light and dark. No console errors.
