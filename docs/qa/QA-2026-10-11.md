# QA — 11 October 2026 (after the UX pass deploy)

## What was checked

- **Production**: every app route redirects to sign-in when
  signed out; security headers present (CSP with nonce, HSTS preload, X-Frame-Options DENY,
  nosniff, Referrer-Policy, Permissions-Policy). Vercel request logs, last 7 days: **no 5xx
  and no error-level entries**.
- **Crawl** (local production build, Chrome): every reachable page as CEO, Management, Legal
  and Loan Officer — 249 pages, 63 Excel downloads — for HTTP errors, console errors, page
  errors, hydration warnings, failed requests and suspicious text (NaN, undefined, Invalid
  Date, [object Object]). Clean.
- **Edge cases**: 46 hostile URLs (`__proto__`, NUL bytes, overlong numbers, bad ids, bad
  dates, inverted ranges, huge page numbers) and edge values in the New loan and mortgage
  quote forms; the search palette with odd input.

## Bugs found and fixed

| # | Bug | Cause | Fix |
|---|---|---|---|
| 1 | Loans, Mortgages, Transactions search with a NUL character (`?q=%00`) → 500 | Postgres rejects NUL in text parameters | `cleanSearch()` (`lib/search.ts`) on every search: control characters become spaces, length capped. |
| 2 | Loans and Mortgages search for a long number (`?q=99999999999`) → 500; search palette error | A State ID compared with an `integer` column overflowed | `asStateId()`: only 1–9 digits count as a State ID; mortgages fall back to house-number search. |
| 3 | Borrower directory with a NUL in the search → React hydration error | The raw search text was rendered back | Cleaned with `cleanSearch` (page and Excel). |
| 4 | Audit log `?before=` with 20+ digits → 500 | `bigint` overflow | Accept at most 18 digits. |
| 5 | Mortgage quote with agency commission = price, a term over 24 months or 100% down showed "Fill in the price…" or saved a $0 loan | Generic client message; server allowed 100% down | Specific messages; server caps down payment at 99%. |
| 6 | Any form: text with a hidden control character → "Something went wrong" | Postgres error 22021/22P05 | `runAction` returns a plain message for those codes. |

Not bugs: 404 console lines on deliberately bad ids are the real not-found pages; a crawl
after 15 idle minutes hit the sign-in page (the idle timeout working as designed).

## Later the same day: landmarks

A stricter axe run (WCAG plus best-practice rules) found two structural issues on every page,
both fixed: the layout's `<main>` contained each page's own `<main>` (two main landmarks), and
the sidebar wasn't a navigation landmark (logo, links and user menu sat outside any landmark).
Now the layout holds the one `<main>`, `PageBody` is a plain container, "Skip to content" lands
on the page title (`#main` on the title block), and the sidebar is `<nav aria-label="Main">`.
22 main pages: no violations, best-practice included.
